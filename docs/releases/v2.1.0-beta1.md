NovaDrive NEXT 2.1.0 (Beta 1) — نجح البناء وكل الاختبارات الآلية؛ لم تُختبر بعد على جهاز السيارة.

## الجديد
- **ملاحة داخل التطبيق:** البحث عن الوجهات، رسم المسار على الخريطة، توجيه خطوة بخطوة مع المسافة ووقت الوصول، إعادة حساب المسار عند الانحراف، توجيه صوتي بالعربي، وخريطة بملء الشاشة قابلة للسحب والتكبير. تستمر الرحلة عند تغيير الواجهة أو فتح تطبيقات أخرى. أمر «خذني إلى …» يوجّه داخل NovaDrive.
- **8 واجهات جديدة:** كلاسيك، Mercedes، Ford، Apple المستقبلية، Jetour، BYD، Haval، TANK. لكل واجهة تخصيص مستقل: فاتح/داكن، اللون، الخلفية (ألوان جاهزة أو صورتك)، والخط.
- **أيقونات ثابتة** لاختصارات CarPlay والموسيقى والهاتف والخرائط في كل الواجهات.

## الإصلاحات
- الإضاءة تعمل على الأجهزة التي تتجاهل إعداد السطوع في أندرويد.
- موسيقى بلوتوث السيارة: عرض اسم المقطع والتحكم عبر أزرار إشعار المشغّل.
- الخرائط بدون مفتاح API (OpenStreetMap).

## لم يتغير
- تصميم واجهتي Tesla وBMW (تمت المقارنة بالصور قبل وبعد).

## قيود معروفة
- البحث والتوجيه يعتمدان على خدمات OpenStreetMap المجانية (Nominatim وOSRM) ويحتاجان اتصال إنترنت؛ لا توجد بيانات زحام مروري.
- الصوت يستخدم محرك النطق في الجهاز.
- السرعة والارتفاع والاتجاه من GPS فقط.
- ملف APK موقّع بمفتاح التطوير (debug)؛ قد يلزم إلغاء تثبيت النسخة القديمة قبل التثبيت.
- أيقونات CarPlay/الموسيقى/الهاتف/الخرائط الحالية مؤقتة حتى تُرفق الصور المرجعية.
